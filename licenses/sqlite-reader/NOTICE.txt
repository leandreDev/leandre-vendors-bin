This is a local extension to ExifTool 13.63, not an upstream ExifTool release.
It reads SQLite 3 database headers using the bundled Perl runtime.
Format documentation: https://www.sqlite.org/fileformat.html
Sources: scripts/exiftool/SQLite.pm and scripts/exiftool_sqlite.py in
https://github.com/leandreDev/leandre-vendors-bin
The complete extension sources accompany third-party-sources.tar.gz.
